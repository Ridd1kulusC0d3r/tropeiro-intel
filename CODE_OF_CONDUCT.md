# Código de conduta

Seja respeitoso, objetivo e construtivo. Críticas são sobre o código e a análise, nunca sobre pessoas.

Uso aceitável: investigação **defensiva** de phishing e fraude, com dados públicos. Não aceitamos contribuições voltadas a vigilância de indivíduos, coleta de dados privados, ou operação ofensiva. Issues e PRs com esse objetivo serão fechados.

Problemas de conduta: abra um aviso privado de segurança no repositório (Security → Report a vulnerability).
