# Security and Responsible Use

Tropeiro Intel is intended for defensive OSINT, phishing analysis, threat intelligence and authorized security research.

## Safe defaults

- Passive collection is the default.
- Direct HTTP probing is disabled by default.
- The project does not implement resource claiming, subdomain takeover exploitation or credential interaction.
- Do not use the project to target private individuals, collect unnecessary personal data or bypass access controls.
- Use public registration/business information and operational identifiers only as needed for the investigation.

## Attribution

Correlation is not identity. Shared hosting, IPs, ASNs, registrars, DNS providers and phishing kits can produce false associations. Reports should distinguish infrastructure relationship, campaign membership, common-operator assessment and real-world identity attribution.

## Reporting a vulnerability

Do not publish secrets, private data or exploit details in a public issue. Use a private GitHub security advisory when available for the repository.
