# Public Release Notes — 3.1.1

This release prepares Tropeiro Intel for public GitHub/Colab use.

Changes from the internal 3.1 build:

- official GitHub/Colab entrypoint;
- Colab Secrets / environment-variable credential loading;
- package metadata and editable-install support;
- CI test matrix;
- public documentation and responsible-use guidance;
- split email/phone correlation evidence;
- more conservative IOC action logic;
- current activity derived from recent observations instead of being assumed;
- investigation-priority score no longer reused as a maliciousness probability.
