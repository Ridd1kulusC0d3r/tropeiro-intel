# Reporting UX

O relatório é o cockpit pós-investigação. Ordem: assessment, ações, IOC decisions, campanha, atribuição, gaps/pivôs, detecção, evidências, fontes e exportação.

`report.html` é local/offline, sem CDN, com filtros, tema claro/escuro, print/PDF e exportação client-side. A marca do projeto é o feijão guerreiro de espadas cruzadas (`docs/assets/logo.svg`).
